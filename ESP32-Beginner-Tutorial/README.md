# ESP32 Beginner Tutorial

**By MK Lattice Studio**

Welcome! This repository contains the source codes for my ESP32 beginner tutorial.

## Projects

1. LED Blink
2. Wi-Fi Connection
3. Wi-Fi Controlled LED

## Hardware
- ESP32-C3 Super Mini
- LED
- 330Ω Resistor
- USB Data Cable

## Software
- Arduino IDE
- ESP32 Board Package

## How to Use
1. Download the project files.
2. Open the `.ino` file in Arduino IDE.
3. Select your ESP32 board.
4. Select the correct COM port.
5. Upload the code.
